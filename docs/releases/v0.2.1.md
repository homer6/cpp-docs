# cpp-docs v0.2.1

A patch release for the skills: install them once for every project, and
start with `/modern-cpp`. The reference pages are unchanged from
[v0.2.0](v0.2.0.md).

Tracking issue: [#137](https://github.com/homer6/cpp-docs/issues/137).

## What's new

- **`make install`, `make update` and `make uninstall`**
  ([#134](https://github.com/homer6/cpp-docs/pull/134)) link the `modern-cpp`
  and `cpp-guidelines` skills into `~/.claude/skills`, pointing back at your
  checkout.
  - `make install` also upgrades an earlier install. It re-points a link to
    another checkout, and moves an older copied folder to
    `~/.claude/skills-backup/` before linking.
  - `make update` pulls the checkout and re-links.
  - `SKILLS_DIR=…` installs somewhere else.
- **Both skills work from any project.** They find the checkout by resolving
  their own link, and `CPP_DOCS` overrides that. `cpp-guidelines` is no longer
  repo-bound.
- **`/modern-cpp` is the preferred entry point**
  ([#136](https://github.com/homer6/cpp-docs/pull/136)). It calls
  `cpp-guidelines` itself. Use `/cpp-guidelines` directly for:
  - a Core Guidelines review or audit with rule IDs;
  - a question about one rule;
  - a focused ownership, lifetime or memory-safety fix;
  - the evals.
- **The README** has a "Use it while you write C++ (Claude Code)" section with
  the install and upgrade steps.

## Upgrading

From a checkout on `main`, run `make update`, or `git pull` and then
`make install`. Earlier installs are upgraded in place.

## What it does not include

The same as [v0.2.0](v0.2.0.md): no MSVC or Windows checks, and no local
compiler implements hive, senders, linalg, simd, RCU/hazard pointers or the
private module fragment. Reflection is verified on GCC 16 only.

## Known issues

No security-relevant issues. No issues are open. The Clang 22 + libc++
baseline still lists 19 genuine libc++ gaps, and the GCC baseline is empty.

## Where it has run

- macOS 14 (arm64): Homebrew GCC 15.2.0, Homebrew Clang 22.1.8 with libc++,
  CMake 4.3.
- Linux arm64: Docker `gcc:16` (GCC 16.2, native arm64 image) with Debian's
  CMake 3.31.
- `make install` against a real `~/.claude/skills` (both links reported
  current), and in scratch folders for every upgrade case.
